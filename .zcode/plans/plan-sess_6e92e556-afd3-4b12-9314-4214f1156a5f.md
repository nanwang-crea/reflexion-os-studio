## 目标
把计划从之前占满右侧一整栏的工作区面板，改成 Codex/ChatGPT 式的**悬浮常驻计划小卡片**：只要当前 session 有计划就显示在对话区右上角，不占聊天流宽度、不推挤消息、不随滚动被顶走；折叠态紧凑，展开态有限高内部滚动。git 变更等其它部分本期不做。

## 实现方案
1. **重写计划卡为悬浮卡片**（`features/chat/PlanCard.tsx`）
   - 组件接收单个 `plan`（ChatView 计算出的“当前计划”）。
   - 折叠态：一行小卡显示清单图标、目标标题（单行省略）、进度 `n/总计`、状态色点，以及**当前步骤预览**（进行中/待处理第一步的标题）；点击展开。
   - 展开态：显示目标 + 状态 + 进度 + 步骤清单 + 摘要，**高度上限约 240px，超出内部滚动**，不遮挡过多对话。
   - 默认：进行中的计划展开，否则折叠。
   - 视觉对齐现有 Codex 风格：低对比边框、浅背景、圆角、紧凑间距，不沿用之前的大色块。

2. **ChatView 承载悬浮卡**
   - 在 `ChatView.tsx` 中计算“当前计划”：优先取状态为 `active` 的计划，否则取 `plans` 中最后一个。
   - 在 `.chat-view` 内渲染 `<PlanCard plan={currentPlan} />`，用绝对定位固定在对话区**右上角**，`z-index` 置于消息之上。
   - 仅当存在计划时显示；不加入 transcript 流，因此不推挤消息、不随滚动被顶到上方，天然解决“聊多了找不到”的问题。

3. **移除右侧面板改动**
   - 删除 `features/chat/PlanPanel.tsx`。
   - `App.tsx`：移除 `planOpen`/`planWidth` 状态、对应 localStorage effect、顶栏计划按钮、`toggleWorkspace`/`togglePlan` 互斥逻辑、`openFile` 里的 `setPlanOpen(false)`、content-area 中的 PlanPanel + ResizeHandle 分支，以及 `PlanPanel`/`ListIcon` 引用；恢复工作区面板原有独立切换行为。

4. **样式与响应式**
   - 在 `features/chat/chat.css` 中用悬浮卡样式替换此前的 `.plan-panel*` 规则：`.plan-float` 绝对定位右上角、对齐居中 transcript 右缘、宽度约 300px、限高滚动。
   - 保持暗色 token、边框、间距一致；窄屏下收窄宽度并保证输入区可用。
   - 计划卡组件结构保留“目标 + 步骤 + 摘要 + 状态”，便于后续在同一浮层内追加 git 变更等区块（本期不实现）。

## 验证
- `pnpm format:check`、`pnpm lint`、根级 `pnpm typecheck`、桌面前端 `typecheck` 全部通过。
- 手动确认：session 有计划时右上角出现常驻悬浮卡；长对话滚动后仍在原位；折叠态显示目标+当前步骤预览；展开态步骤限高内部滚动；切到无计划的会话不显示；不影响聊天流布局与工作区面板。
