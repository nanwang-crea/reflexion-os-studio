## 验证范围

故障注入先在旧构建上复现：已取消请求发卡、连续两次终态事务回滚异常逃逸、卸载清理失败恢复目录。新增测试验证修复后的结算、通知失败、事务回滚、卸载隔离与恢复、项目删除语义、策略注入、旧 epoch 清理和无效参数指纹。

通过：格式、lint、根级和前端 typecheck、依赖包与前端构建、Rust 格式检查、Tauri 宿主 check。Agent 内核 86 项、相关 Runtime 185 项、契约 83 项、runtime-client 28 项、Rust 240 项、相关 UI 6 项，共 628 项测试通过。Rust Seatbelt/PTY 测试在外层沙箱下有 12 项环境失败，沙箱外重跑全部通过。

`pnpm build:desktop` 通过，生成自包含 macOS `.app` 与 ARM64 `.dmg`，嵌入前端资源校验通过。未执行全仓 `pnpm test`、Windows/Linux 真机、真实模型或长稳验收；本次测试范围为受影响领域及仓库规定的原生构建检查。

终态持久化故障、审批取消、目录重命名/删除、哈希与集合使用 Node/SQLite 标准 API，三平台共用逻辑；Windows 文件占用导致的清理失败通过故障注入覆盖。macOS 上的构建和测试不能替代 Windows/Linux 真机、真实模型或长期运行验收。

## 提交前审查补修

- 工具完成通知与 Run 终态通知原先共用一个 try/catch，第一条工具通知失败会跳过其余事件。改为逐条隔离通知异常，并验证后续工具事件、Run 终态事件和一次性回调均继续执行。
- 卸载时递归清理失败且 manifest 已删除，随后重装同名 Skill 后，启动恢复原先仍试图读取旧 manifest。现已根据受管隔离目录身份和正式目录存在性清理旧残留；回归同时验证新包正文、启用状态和 Registry 保留。
- 两项新增测试均先复现失败，修复后相关 Runtime 185 项和 UI 6 项回归全部通过。此前未受影响的内核、契约、客户端与 Rust 检查结果继续有效。
