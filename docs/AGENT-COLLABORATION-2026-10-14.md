# 对话驱动的 Agent 协作

## 产品方向

用户在主对话给出目标，Primary 自主规划、调用工具、动态委派、验证并交付。
需要关键输入或操作授权时再询问。右侧协作面板呈现真实计划与动态 Agent 树，
不提供手动 DAG 编排。浏览器、文件和协作是独立的右侧 Surface。

角色模板在 Agent 页面管理，领域分类（开发/写作/研究等）与作用范围
（全局/项目）独立。执行实例绑定父会话项目工作目录；模板不能指定任意目录
或扩大权限。并行写操作继续由根级 mutation coordinator 协调。

角色允许继承父模型或由用户指定 Provider/模型/思考强度。模型建议只选择模板，
不能在 task 参数中任意切模型。指定配置不可用则失败并回传明确错误，不静默回退。
实例和 Delegation execution 快照保存实际 Provider/模型/思考等级与工作空间归属。
递归创建子实例时继承当前实例实际模型；角色模板仍可明确覆盖。

协作 Skills 表达角色选用、交接、检查和完成标准，允许按任务动态调整；
不把本次执行的路径、临时指令或机密自动保存。用户可审阅并保存协作方法，
角色提示词/模型/权限留在模板。Skills 不授予权限，Runtime 继续限制预算、
深度、并发、审批、沙箱和持久化终态。

## Workflow 退役

稳定实现保留于 codex/archive-workflow-stable-2026-10-14；完整历史与未完成双栏草稿保留于 codex/archive-workflow-2026-10-14。
主分支删除前端编排器、Workflow 命令/API、执行与生成服务。历史 schema、
迁移和 Store 读取边界保留，启动仅收敛旧活动记录，不重放执行，不销毁历史。
已退休的内部会话继续只读隐藏，不允许通过普通消息命令恢复旧节点执行。

## 平台与验收

模型与模板、Skills、SQLite 和协作 UI 在 macOS/Windows/Linux 采用相同
Node/React 实现。项目路径使用 node:path；OS 工具沿用现有平台沙箱。
事件订阅挂载一次，回调读取 latest ref；事件合并刷新，无空闲轮询。
模型隔离、项目范围、重启持久化、故障无回退、协作图与角色配置须有回归。
真实模型质量、Windows/Linux GUI 与长期运行仅在实际验收后标为完成。

验证与限制见 [验收记录](AGENT-COLLABORATION-VALIDATION-2026-10-14.md)。
