# Agent 运行上限与设置入口

入口：**设置 → Agent 运行时**。8 项预算支持“使用默认值 / 自定义上限 / 不限制”，也可点击“将 8 项可选上限设为不限制”，检查后保存。保存仅用于之后启动的运行；已启动的任务保留启动时的设置。

| 分组          | 设置项                        | 默认                             | 支持不限制                                     |
| ------------- | ----------------------------- | -------------------------------- | ---------------------------------------------- |
| 循环          | 最大轮次（模型调用上限）      | 100 轮                           | 是                                             |
| 循环          | Run 总时长上限                | 7200 秒                          | 是                                             |
| 循环          | Run token 总预算              | 2 亿，累计输入和输出             | 是                                             |
| 循环          | 工具调用次数上限              | 1000 次                          | 是                                             |
| 循环          | 续写轮次上限                  | 连续 2 次；自定义 0 禁用自动续写 | 是                                             |
| 子 Agent 委派 | 整棵委派树的活跃子 Agent 上限 | 4 个，终态释放名额               | 是                                             |
| 子 Agent 委派 | 单个子 Agent 超时             | 不单独限时                       | 是                                             |
| 子 Agent 委派 | 单个子 Agent 输出预算         | 12000 token，累计输出            | 是                                             |
| 子 Agent 委派 | 并行子 Agent 数               | 2 个，最多 8 个                  | 否，保留资源边界                               |
| 子 Agent 委派 | 最大委派深度                  | 1 层，最多 4 层                  | 否，保留递归边界                               |
| 网络          | 请求超时                      | 120 秒，10–600 秒                | 否，检测响应头和流数据断线；持续输出会刷新计时 |
| 网络          | 请求重试次数                  | 5 次，0–15 次                    | 否，避免失败请求永久重试；0 不重试             |
| 网络          | 初始退避时间                  | 1 秒，1–120 秒                   | 否                                             |
| 网络          | 最大退避时间                  | 60 秒，1–120 秒                  | 否，须不小于初始值                             |
| 循环          | 反思阈值                      | 失败 2 次，0–10 次               | 非上限项；0 禁用反思                           |

“不限制”只取消该项应用级预算，父任务预算、父任务取消、权限审批和重复无进展检测仍然生效。所有应用级预算都不等于服务商配额、上下文窗口或单次输出无限。

单次输出和上下文参数入口：**设置 → 模型供应商 → 选择供应商 → 模型独立配置**。留空表示默认或继承，仍受模型和服务商硬上限限制；Anthropic 未指定最大输出时使用当前协议的默认值。

触限文案遵循“停止原因 + 当前阈值 + 具体字段路径 + 重新启动生效”。例如：

> 本次运行累计输入与输出 token 超过 200000000。可前往「设置 → Agent 运行时 → 循环」调整「Run token 总预算」或选择“不限制”；保存后重新发起任务。

持久化通过可选 `unlimitedLimits` 字段保存明确取消的预算名；既有数字及 null 的默认语义保留，旧配置不自动放宽。Infinity 只用于内存中的比较，不写数据库、协议或执行快照；无总时长限制时不创建定时器。

子 Agent 数量与并发限制均只统计未结束的委派（pending / running，包括子 Run 等待审批或用户输入的阶段）。已完成、失败、取消的历史委派保留记录，不占用名额；恢复任务时也排除这些终态。数量限制不再作为累计创建次数预算，Run 总时长、token 与工具调用预算继续独立生效。

## Provider 网络错误诊断

OpenAI Chat、OpenAI Responses 与 Anthropic 的连接/断流错误统一显示失败阶段、已知底层错误码、当前请求是否收到响应数据，以及实际重试次数（初次请求不算重试）。本地空闲超时会明确显示等待阈值；收到数据后刷新计时，不是整段生成的总时限。

例如：`读取响应流失败（已收到部分响应数据）：响应流意外中断；UND_ERR_SOCKET：连接在传输期间关闭。已重试 5/5 次（共 6 次请求）。`

底层原因沿有界 cause/AggregateError 链提取，只展示已知网络/TLS 错误码和固定说明，不输出原始 socket、请求头或任意异常详情。无法识别时明确说明底层未提供可识别错误码；连接断开本身不能证明是哪一方导致。用户取消仍按取消处理，不显示为网络故障。

### 请求尝试与中断片段

每次实际 HTTP 请求独立编号并保存到所属消息的 `requestAttempts`，含开始/结束时间、状态、阶段、HTTP 状态、供应商请求 ID、首批数据/正文/思考耗时、最长无数据间隔、接收字节数及脱敏错误。初次请求为第 1 次；退避期间取消不会创建不存在的下一次请求。记录不保存地址、请求体、请求头或完整错误对象。

中断尝试的正文和思考保存在独立预览中；重试只重置当前答案，不删除旧尝试。正式模型历史仍只使用原有消息内容与完整工具结果，不把失败片段、诊断或半截工具参数带入。请求尝试记录只在数据库中保留，供开发排查使用，不进入用户界面；进行中的请求由既有的重试/等待指示表达。成功尝试在正式答案落库后仅保留诊断；清理预览与写入正式答案使用同一次数据库更新，避免两者之间的崩溃窗口。

流读取期间按数据到达每两秒至多写一次预览检查点，正常结束、失败或取消时补写终态；无常驻定时器。进程异常退出后将运行中的记录标为中断，保留最后检查点，末尾尚未检查点的内容可能丢失。

三种协议统一对错误消息和已配置密钥/附加请求头值脱敏。TLS 证书及明确的地址格式错误不重试；流内明确的限流/过载/服务端临时故障可在原有预算内重试，认证错误优先快速失败。每轮模型调用仍共用一个重试计数，不新增第二层重试预算。工具执行仍等待完整模型结果。

## 请求重试退避

网络分组新增初始退避时间（默认 1 秒）和最大退避时间（默认 60 秒），均可设为 1–120 秒，最大值不得小于初始值（留空按默认值比较）。每次重试等待初始时间乘以 2 的递增幂，达到最大值后保持不变。服务端提供 Retry-After 时取较大值，最终封顶 120 秒。旧配置继续使用原默认值，无需数据库迁移；保存仅对新启动的运行生效。macOS、Windows、Linux 共用 Runtime 的计时和配置逻辑。
