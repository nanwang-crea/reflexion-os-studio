# 手机会话接入实现与代码 Review

分支：`codex/mobile-session-access`。本次为实现者自审，未合并主分支。

## 已交付

- Runtime 的 schema/来源授权/业务调用/错误映射收敛到统一请求入口；桌面继续走 stdio。
- 可订阅事件总线隔离客户端投递故障；会话历史读取复用同一个 Store 投影。
- 按需启动局域网 HTTPS，随机端口、本机网卡选择、一次性两分钟二维码、电脑核对配对码。
- 设备凭据仅在内存与 HttpOnly/Secure/SameSite cookie；八小时设备授权、撤销与停止接入。
- 手机独立入口复用 ChatView、Composer、消息、工具轨迹、队列、审批、附件与子任务轨迹组件。
- 重连先恢复 canonical 历史与有界活动草稿、待审批/问题和 Danger 状态；写请求不盲重放。
- EndpointProvider 独立于设备与会话业务，支持对外 URL 路径前缀，为公网出站中继预留。
- 手机构建只打包所需依赖图；随桌面安装包分发，不要求目标机器安装 Node 或另起后端。

## Review 发现并修复

1. **共享模块导入依赖浏览器全局**：改为显式 Web 入口标记与延迟初始化，桌面/Node 测试保留既有通道。
2. **构建相对 URL 与打包校验不兼容**：宿主校验同时识别绝对和相对 assets URL，并补 Rust 回归。
3. **跨客户端回执碰撞与恢复**：手机操作按设备命名空间隔离；查询与事件只投影本设备回执。
4. **过度暴露执行内部字段**：手机历史/事件剥离 Provider continuation 与请求诊断；不开放 Provider 密钥配置。
5. **同一设备多页重连互踢**：保留已有流，按设备两个/总计十六个限制新增流；慢连接达到背压上限后独立断开。
6. **停止与异步启动竞争**：启动 generation 检查关闭迟到 endpoint，停止后不会重新开放端口。
7. **大草稿挤掉审批**：草稿超限明确提示；控制确认继续保留，不能让审批在恢复时静默消失。
8. **手机隐藏已有 Danger 状态**：快照与事件同步已有租约，复用危险横幅与关闭动作；手机不能新建 Danger 授权。
9. **公网中继共享来源地址**：业务限流按已认证设备区分；不依赖 X-Forwarded-* 声明身份。
10. **schema 注册表原型命中**：未知命令先检查 own property，避免 constructor 等名称逃逸校验入口。
