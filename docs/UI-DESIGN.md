# 桌面界面的视觉与产品约定

支持浅色、深色和跟随系统三种外观。浅色使用白色内容区、浅灰侧栏与深色文字；深色保留原有配色。侧栏作为导航层，主内容作为阅读层，卡片、输入框与弹层作为操作层。代码编辑器、diff 与终端同步主题，保留语法和 ANSI 语义色。

- 全局深色基线在 `styles/style.css` 定义，浅色变量与对比度适配在 `styles/themes.css`；跨页面的标题、导航、卡片、焦点与响应式规则在 `styles/product-surfaces.css` 维护，具体布局仍归功能模块。
- 技能、指令与自动化页共享内容宽度、标题尺度、页面留白与说明文字层级。设置页保留分类导航与独立内容区。
- 导航选中态同时使用背景和边缘标记；键盘焦点始终可见，行尾操作在键盘聚焦时显示。减少动态效果的系统偏好对整个界面生效。
- 权限与运行状态使用语义色，不用装饰色代替警告。模板选择必须说明其影响，避免让用户误认为选择模板会启动子 Agent。
- 占位页面如实说明尚未开放的能力，不提供不可兑现的订阅或操作入口。
- 窄窗口缩小留白，工具栏允许换行；macOS、Windows、Linux 使用相同 CSS 与共享 Select，系统文件选择器继续使用原生对话框。三平台真机与高 DPI 验收分别记录。

本轮调整不增加运行配置模式或自动化能力。委派仍由模型调用工具触发；提示词的遵循率需要后续真实模型任务评估，不能以静态检查代替。

## 外观设置

设置 → 外观提供带预览的原生单选项，支持键盘导航与焦点提示。选择立即生效；偏好保存到 WebView localStorage（`appearance.theme`），初始化时在 React 首次渲染前恢复。已有安装默认深色；存储不可用时仍允许本次切换。跟随系统使用 `matchMedia` 变化事件，固定主题不随系统切换；无轮询、无常驻计时器。主题不进入 Runtime 业务配置，三平台使用同一前端实现。

## 控件与空状态统一（2026-10-09）

- 全局字体为系统 UI 字体栈，正文 14px、说明 13px、页面标题 24px；间距使用 4px 基础尺度，控件圆角 8px、内容面板圆角 12px。
- 主要操作统一使用主题 accent / on-accent；次要操作使用 ghost；危险确认使用独立深红实底与白字，避免浅红背景下的文字对比不足。键盘焦点统一使用 focus-ring，不随页面自行指定灰色。
- 确认弹窗采用主题背景与阴影，消息可换行、长文本可折行、动作允许换行；既有取消初始焦点、Escape 与焦点恢复行为保留。
- 聊天、项目文件、文件预览、Provider 和 MCP 空状态复用 EmptyState 的图标、标题、说明层级，并给出当前页面可执行的下一步。
- 清理未定义的 surface-hover、text-primary、warning 色变量，避免选中态与警告颜色在不同 WebView 中退化。
- 此次只调整展示与既有控件样式，不新增事件订阅或计时器。Windows / Linux 与高 DPI 真机外观仍需对应环境验收。
