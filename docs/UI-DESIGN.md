# 桌面界面的视觉与产品约定

采用统一深色工作界面：侧栏作为导航层，主内容作为阅读层，卡片、输入框与弹层作为操作层。编辑器保留独立背景，避免破坏代码主题。

- 全局色彩在 `styles/style.css` 定义；跨页面的标题、导航、卡片、焦点与响应式规则在 `styles/product-surfaces.css` 维护，具体布局仍归功能模块。
- 技能、指令与自动化页共享内容宽度、标题尺度、页面留白与说明文字层级。设置页保留分类导航与独立内容区。
- 导航选中态同时使用背景和边缘标记；键盘焦点始终可见，行尾操作在键盘聚焦时显示。减少动态效果的系统偏好对整个界面生效。
- 权限与运行状态使用语义色，不用装饰色代替警告。模板选择必须说明其影响，避免让用户误认为选择模板会启动子 Agent。
- 占位页面如实说明尚未开放的能力，不提供不可兑现的订阅或操作入口。
- 窄窗口缩小留白，工具栏允许换行；macOS、Windows、Linux 使用相同 CSS 与共享 Select，系统文件选择器继续使用原生对话框。三平台真机与高 DPI 验收分别记录。

本轮调整不增加运行配置模式或自动化能力。委派仍由模型调用工具触发；提示词的遵循率需要后续真实模型任务评估，不能以静态检查代替。
