# 角色技能与完整角色包

角色关联统一技能库，绑定 skillId 与 mode（preferred 按需优先、startup 启动加载）。全局角色仅绑定全局技能，项目角色可绑定该项目与全局技能。绑定不授予工具权限。执行前解析可见且启用的技能，缺失明确失败；实例保存技能版本与实际指令快照。按需技能通过 skill.use 加载，启动技能由 Runtime 注入。

轻量 JSON 分享保留技能引用。完整 ZIP 使用 role.json 与 skills/<skillId>/ 完整标准包；不带本机 Provider ID 或密钥，导入模型继承，角色默认停用。导入先校验和预览，显示目标作用域、技能及复用/安装状态；同 id 的内容或版本不同则拒绝覆盖。ZIP 入口限制路径、大小、数量、文件类型，技能继续经已有包校验和安装器安装，不执行脚本；失败清理本次新装技能。

三平台共用 Node ZIP 编解码、node:path 与现有安装器；文件选择仍走系统对话框，网页上传仅传选中文件字节。macOS/Windows/Linux 真机验收需分别记录。

## 当前限制与验证

单角色最多关联 20 项技能；启动技能说明合计不超过 100KB，ZIP 压缩前后均不超过 32MB、最多 4000 个文件。一次导入只针对一个角色；团队轻量 JSON 保留技能引用，团队完整 ZIP 不在本次范围。ZIP 导入模型默认继承，可在角色编辑器选择本地 Provider；固定模型的名称与思考偏好保存在 ZIP 元数据中，不携带 Provider ID。禁用或不同项目的同 id 技能不自动启用或跨域复用。由 ZIP 新装的技能没有临时解压目录更新源，需要在技能页显式选择本地包更新。

新增加载 effect 仅依赖项目 id，卸载/切换丢弃过期请求；没有新增常驻订阅、轮询或计时器。真实模型质量、dev 三进程空闲资源对比与 Windows/Linux 真机仍待验收。
